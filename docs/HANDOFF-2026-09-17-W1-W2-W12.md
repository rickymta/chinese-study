### Việc người dùng phải tự làm trên máy dev

```bash
# compose dev (MacBook): init script chỉ chạy khi volume trống — volume cũ thì tạo tay:
psql -h localhost -U postgres -c "CREATE ROLE af_cms LOGIN PASSWORD '<mật khẩu>';"
psql -h localhost -U postgres -c "CREATE DATABASE af_cms OWNER af_cms ENCODING 'UTF8' TEMPLATE template0;"
cp backend/services/cms-backend/src/AntFarm.Cms.Api/appsettings.Development.json.example \
   backend/services/cms-backend/src/AntFarm.Cms.Api/appsettings.Development.json   # điền mật khẩu + email vào CmsAdmin:BootstrapEmails
```

- Thêm `"http://localhost:3290"` vào `Auth:AllowedOrigins` trong `appsettings.Development.json` **thật** của identity-service (file example đã có; file thật gitignore nên không tự cập nhật). Thiếu ⇒ đăng nhập admin 403 `ORIGIN_NOT_ALLOWED`.
- Restart identity-service để token mới có `af-cms` trong `aud` (phiên cũ 401 ở cms-backend tối đa 15 phút).
- Chạy: `dotnet run --project backend/services/cms-backend/src/AntFarm.Cms.Api --launch-profile http` (5290), `cd frontend && yarn workspace @af/admin dev` (3290).
